# Inbox

아직 분류하지 않은 생각, 모바일 캡처, 임시 메모를 잠시 두는 곳이다.

## 처리 규칙

- 원문 보존 가치가 있으면 `sources/`로 이동한다.
- 정리된 지식이 되면 `wiki/topics/`, `wiki/concepts/`, `wiki/principles/`, `wiki/entities/`, `wiki/syntheses/` 중 하나로 승격한다.
- `inbox/`는 **사람 전용**이다. 자동 뉴스 수집 루틴의 산출물은 여기에도, `wiki/` 어디에도 두지 않는다 — 전부 최상위 `routine-news/` 안에서만 산다.
- 일주일 이상 남아 있는 노트는 삭제, 병합, 승격 중 하나로 처리한다.
