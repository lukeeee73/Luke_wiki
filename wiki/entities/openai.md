# OpenAI

AI 연구 회사. ChatGPT, GPT 시리즈 모델, Sora 비디오 생성 모델 등을 개발했다.

## 주요 제품/모델

- **ChatGPT**: 대화형 AI 플랫폼
- **Codex**: 코딩 도구
- **Sora**: 비디오 생성 모델 (→ 2026년 종료)
- **RealTime API**: 음성 입출력 개발자 API

## 주요 사건

### Sora 서비스 종료 발표 (2026)
- 웹/앱 접근: 2026-04-26 종료
- API: 2026-09-24 종료
- **재정 상황**: 일일 약 $1M 손실; 최고 DAU ~100만 → 이후 절반 이하로 급감
- **전략적 이유**: 수익성 높은 투자로 자원 재배치
- Sora 팀 → 월드 모델, 로보틱스 장기 프로젝트로 재배치
- 발표 전 처리 리소스를 신모델 "Spud"(코딩/엔터프라이즈 제품)로 이전
- **Disney 파트너십 종료**: Disney 캐릭터 라이선스 + Disney 영상 훈련 + Disney 최대 $10억 투자 계획이 Sora 종료로 사실상 무산
