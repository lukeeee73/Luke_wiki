# OpenAI

AI 연구 회사. ChatGPT, GPT 시리즈 모델, Sora 비디오 생성 모델 등을 개발했다.

## 주요 제품/모델

- **ChatGPT**: 대화형 AI 플랫폼
- **Codex**: 코딩 도구
- **Sora**: 비디오 생성 모델 (→ 2026년 종료)
- **RealTime API**: 음성 입출력 개발자 API
- **Spud** (코드명): 코딩/엔터프라이즈 제품용 신규 모델

## 주요 사건

### Sora 서비스 종료 발표 (2026)

**종료 일정:**
- 웹/앱 접근: 2026-04-26 종료
- API: 2026-09-24 종료

**재정 상황:**
- 일일 약 **$1M(백만 달러)** 손실
- 모바일 앱 출시 직후 최고 DAU ~100만 명 → 이후 절반 이하로 급감

**전략적 결정:**
- Sora 팀 내부에서는 ChatGPT에 통합되는 새 비디오 모델 훈련을 제안했으나, 경영진이 비용 문제로 비디오 생성 전면 취소 결정
- 발표 전 Sora의 처리 리소스를 코딩/엔터프라이즈 제품 지원 신모델 **"Spud"**로 이전
- Sora 팀 → 월드 모델, 로보틱스 장기 프로젝트로 재배치
- 비디오 생성 분야 주도권 포기 → 경쟁사들에게 개방된 시장

**Disney 파트너십 붕괴:**
- 2025년 말 OpenAI-Disney 주요 파트너십 체결:
  - Disney: OpenAI에 최대 **$10억(1 billion USD)** 투자 예정
  - OpenAI: Disney 캐릭터 라이선스 취득, Disney 영상으로 모델 훈련
  - Disney: Disney+ 콘텐츠, 사전 제작 시각화, 마케팅 특수 효과에 Sora 활용 예정
- Sora 종료 공개 **1시간도 안 되어** Disney에 통보 → "충격적인 비즈니스 결례"로 묘사
- **Sam Altman**: Josh D'Amaro(Disney CEO)에게 알리는 것이 "끔찍했다(felt terrible)"고 발언
- 파트너십 사실상 종료
